# Keybindings & Navigation Cheat Sheet

## 1. Prefix Bindings (`Ctrl + a` by default)

| Keybinding | Action Description |
| :--- | :--- |
| **`Prefix + s`** | Toggle session dock sidebar open / close |
| **`Prefix + P`** | Swap subpane (terminal) position (Top ↔ Bottom) |
| **`Prefix + T`** | Open 38-theme interactive picker with live ANSI preview |
| **`Prefix + /`** | Open searchable command palette |
| **`Prefix + h`** / **`?`** | Open interactive help viewer popup |
| **`Prefix + |`** / **`%`** | Work-pane safe horizontal split (preserves dock geometry) |
| **`Prefix + _`** / **`"`** | Work-pane safe vertical split (preserves dock geometry) |

## 2. Inside the Session Dock TUI

| Key | Action |
| :--- | :--- |
| **`↑` / `k`, `↓` / `j`** | Navigate session rows |
| **`Enter`** | Switch immediately to selected session (0.75ms fast-path) |
| **`c`** | Create new named session |
| **`d`** | Delete / Archive current session |
| **`o`** | Open session archive & restoration view |
| **`P`** | Toggle / Swap subpane position |
| **`h` / `?`** | View keybinding help popup |
| **`q` / `Esc`** | Close dock sidebar and return to work pane |
